# fightev — доводка до портфолио-уровня

Рабочая ветка: **`portfolio-pass`**. `main` не трогаем до конца работы —
`.github/workflows/deploy.yml` деплоит на каждый push в main, и туда же автоматически
пишет `publish_site.py` (пн 03:00, вт 18:00, только `public/data/*.json`).
Раз в день подтягивать: `git merge main`.

Этот файл в сборку не попадает: vite копирует только `public/`.

**Исходная оценка (аудит 2026-09-12): 6/10.** Сайт ≈7, кейс как документ ≈5.
Цель — 8: кейс показывает процесс, ни одно заявление не опровергается замером.

Один пункт — один коммит: `case: P0-1 новый H1`.
